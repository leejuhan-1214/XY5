02 / DBSCAN

고온 영역을 군집으로 읽다

관측 장면별 분석

군집중심 위도·경도면적 (ha)평균 LST최고 LST격자 수

면적은 연구 경계 안으로 분류된 분석 셀의 합입니다. DBSCAN 잡음점도 전체 고온 면적에는 포함되며 군집 면적과 따로 집계합니다. 셀보다 작은 형상은 표현하지 않습니다.

03 / 동일 조건의 모의실험

같은 자원, 다른 배치

배치 탐색의 조건

계산 후 조건과 선택 결과를 표시합니다.

MCLP는 거리 기반 수요 포괄의 탐욕적 근사입니다. 유전 알고리즘은 제한된 후보 탐색이며 전역 최적해를 보장하지 않습니다.

열의 이동을 어떻게 해석하나요?

표면과 기층의 열 저장·교환, 인접 영역의 교환과 별도 대기층의 바람 이동을 단순화해 계산합니다. 흐름은 모델 가정에 따른 것이며 실제 관측 경로나 보행 높이의 기온이 아닙니다.

04 / 관측과 모델의 독립 비교

관측값에 맞추지 않고, 오차를 확인하다

화소별 LST 보정 없음

각 촬영일의 기상으로 실행한 Model 1을 같은 촬영 시각의 Landsat LST와 비교합니다. 아래 위성 장면은 모델 온도를 보정하는 데 사용하지 않습니다. 관측 초기화·학습과 분리된 참고 평가이며, 시간별 열 이동 전체의 검증을 뜻하지 않습니다.

자료 로딩 후 사용 가능한 촬영일과 기상을 확인합니다.

촬영일시각 KST유효 격자MAE °CRMSE °C평균편향 °CR²

서로 다른 연도의 토지피복·건물 상태 변화, 격자형 기상과 미확인 재질은 오차 원인이 됩니다. R²는 음수가 될 수 있으며 나쁜 결과도 그대로 표시합니다.
